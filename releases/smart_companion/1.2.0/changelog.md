## New feature **Teleprompter** as requested by **John** from Discord.

- You can now add Teleprompt using the Teleprompter button on Companion
- The prompt text will scroll on the top of the screen, at eye level if you wear the glasses
- You can adjust the scrolling speed using the scroll bar
- You can adjust the text size and colour
- Teleprompter will scroll as you speech using speech to text recognition

## Bug fixes

- Fixed a bug where Left and Right mouse button don't work right on Touchpad control mode
- Fixed a bug displayed incorrectly on 3 button navigation devices
